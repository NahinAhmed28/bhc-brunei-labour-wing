# Views Pdf Feature

## Generate category-coded token references
Automatically generated token references use the selected service category code followed by a hyphen and eight random digits (for example, DL-01234567). Token PDFs show received/generated dates, creator, requirement, and notes; omit approved-worker, BHC-number, and file-holder fields.
